# Blockers and decisions

No new paid infrastructure, paid inference, production deployment, merge or release authorized. Premium staysOFF and free-first. All routine reversible development is authorized.

Evidence blockers: actual deployed provider/Premium/version state, credential scopes/environment approval settings, real Docker isolation, macOS/device keyboard geometry and sustained production SLOs. These are missing evidence, not permission to bypass controls. Exact gap blockers are in gaps.json.

Implementation decisions: preserve existing controllers and receipts; extend typed deterministic evidence rather than exempt constraints based on model claims. Validate complete candidate diffs including deletions/renames. Restore spend monotonically and atomically reject invalid updates. Bound request size explicitly rather than silently truncating requirements. Generated workflows may be prepared, but secret-bearing execution/publishing must not bypass owner approval. Merely being a draft is not isolation.
