KappaForge 2.0.0 upgrades the existing app and website with a shared Settings interface and actual backend usage tracking.

- Nine searchable Settings sections, responsive controls, accessible labels, light/dark appearance, response style, language and custom instructions.
- Authenticated 90-day Gemini attempt history with provider-reported tokens, latency, error/fallback rates, UTC trends, advisory monthly budgets and JSON/CSV export. Older calls cannot be reconstructed. Missing costs, provider balances and quotas remain unavailable; no invented usage.
- Live discovery of backend-supported Gemini Flash models. Manual selection or automatic Lite/full-Flash preference, bounded to two distinct provider attempts. Response-detail presets control output caps; they do not claim native thinking controls.
- Memory browsing, text/category search, selective deletion, encrypted export/import, categories and deletion-aware synchronization. Existing AES-GCM/PBKDF2 keys, chat storage and authentication remain intact. Recovery requires your existing vault passphrase, independently enabled on each device.
- Shared Update Center reads GitHub release notes and IPA assets. Web and installed IPA versions are shown separately.
- Native iOS: bundled web interface, icon assets, Keychain credential migration, opt-in Face ID/Touch ID app lock with passcode recovery, native JavaScript dialogs, document import and encrypted-backup sharing.
- Existing project, review, build-result and task workflows retained. Diagnostics redact credentials and keep session-only errors. Source indexing is distinct from Gemini usage.

Validation: shared-source/version checks, Python regression suite, JavaScript unit/backend integration tests, desktop Chromium and mobile WebKit browser tests gate the website deployment. iOS simulator build/launch, unsigned iPhone build, bundle/icon checks and IPA ZIP integrity checks gate IPA publication. Consult the matching GitHub Actions run for results.

Installation: download KappaForge-unsigned.ipa on iPhone, then import it in SideStore from Files. SideStore must already be paired and configured with a working Apple account. Use the same signing account and bundle identifier to preserve existing installed data. The IPA cannot install or update itself without signing.

Limits: physical-device Face ID/Touch ID, Keychain persistence across SideStore resigning, native file-picker behavior and the full SideStore install flow still require device testing. WebKit automation approximates mobile Safari but is not physical iPhone Safari testing. Gemini pricing is unavailable by default; operator-configured rates must include a source and date. Browser credentials retain the pre-existing local storage behavior; encrypted cloud backups exclude credentials. Usage records are authenticated server metadata, not part of the end-to-end encrypted memory vault. Memory-note search is lexical; semantic search continues to apply only to source-code indexes. Dependency/security vulnerability scans are not automated by this release. Task history uses existing GitHub and latest-device-task surfaces.
